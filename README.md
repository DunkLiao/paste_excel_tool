# EXCEL 貼值處理工具 使用手冊

EXCEL 貼值處理工具是一個 Windows 桌面程式，會依照「EXCEL貼值清單」的指示，把來源活頁簿的儲存格內容以「值」貼到目的活頁簿，取代人工一格一格複製貼上。程式已打包成免安裝的 `PasteExcelTool.exe`，目標電腦不需要安裝 Python，但**必須安裝 Microsoft Excel**（程式是透過 Excel 本身來讀寫檔案）。

## 快速取得與執行

- 執行檔位置：`dist\PasteExcelTool.exe`（單一檔案，約 12.9 MB，免安裝、免 Python）。
- 直接雙擊即可開啟，不需要管理員權限。
- 首次執行若出現藍色「Windows 已保護您的電腦」視窗，點「更多資訊」→「仍要執行」。
- 系統需求：Windows + Microsoft Excel。未安裝 Excel 時，按「開始執行」會無法操作活頁簿（程式會顯示錯誤訊息）。

## 快速開始

1. 先**關閉 Excel 中所有相關檔案**，避免檔案被鎖定。
2. 開啟你的清單檔，確認裡面有一個工作表名稱是「EXCEL貼值清單」（名稱可在程式介面改）。
3. 在該工作表第 1 列填入 8 個標題（`I` 欄標題由程式自動寫入，可留空）：`A` 來源EXCEL檔案路徑、`B` 來源工作頁名稱、`C` 來源儲存格位置、`D` 來源範圍是否為UsedRange(Y)、`E` 目的EXCEL檔案路徑、`F` 目的工作頁名稱、`G` 目的儲存格位置、`H` 目的儲存格為合併儲存格(Y)。
4. 從第 2 列開始，每一列寫一筆「從哪裡貼到哪裡」。檔案路徑請用**完整絕對路徑**，例如 `D:\報表\2026-11\來源.xlsx`（程式不會展開 `%USERPROFILE%` 這類環境變數）。
5. 雙擊 `PasteExcelTool.exe`，在「清單檔案」按「瀏覽…」選取剛編輯的清單檔，並確認「清單工作頁」是 `EXCEL貼值清單`。
6. 按「開始執行」，等待進度條跑完。
7. 完成後查看下方結果清單，以及清單檔 `I` 欄「錯誤訊息」——成功會顯示「成功」，失敗會顯示原因。

```mermaid

    A --> B{"檔案存在且<br/>工作頁名稱已填?"}
    B -->|否| A
    B -->|是| C["背景啟動隱藏的 Excel<br/>開啟清單檔並寫入 D1、I1 標題"]
    C --> D{"A 欄有資料列?"}
    D -->|否| D1["結果清單顯示：清單無資料"]
    D -->|是| E["讀入 A~H 欄內容<br/>清空 I 欄舊結果"]
    E --> F{"按下中止?"}
    F -->|是| F1["記錄「使用者已中止」<br/>後續列不處理"]
    F -->|否| G["開啟來源檔與目的檔<br/>取得工作頁與範圍後貼值"]
    G --> H{"還有下一列?"}
    H -->|是| F
    H -->|否| I["儲存所有貼值成功的目的檔"]
```

整個過程在同一個程式內完成：先驗證輸入，再隱藏啟動一個 Excel 實例處理所有列，最後統一儲存，最後才顯示統計。中途失敗只影響該列，不會中斷其他列。

## 操作介面

程式視窗標題為「EXCEL 貼值處理工具」，由上而下分成四個區塊。

### 設定

| 元件 | 說明 |
|---|---|
| 清單檔案 | 要處理的清單檔完整路徑，可直接輸入或按「瀏覽…」選取 |
| 瀏覽… | 開啟檔案選擇視窗，支援 `*.xlsx`、`*.xlsm`、`*.xlsb`、`*.xls` |
| 清單工作頁 | 清單所在的工作表名稱，預設 `EXCEL貼值清單`，可自行改成其他名稱 |

### 動作按鈕

| 按鈕 | 行為 |
|---|---|
| 開始執行 | 檢查檔案與工作頁名稱後，在背景執行緒開始處理；執行中會變灰 |
| 中止 | 標記中止，**目前這一列做完後**才停止，後續列不再處理 |
| 清除記錄 | 只清空下方結果清單，不會動到 Excel 檔案 |
| 離開 | 關閉程式視窗 |

執行期間「開始執行」停用、「中止」可用；結束或發生錯誤後會恢復。處理中請不要按「離開」，否則背景的 Excel 可能來不及正常關閉。

### 進度與狀態

進度條顯示「已處理列數 / 總列數」，下方狀態列依序顯示：`處理中…`、`處理中… n / m`、`處理完成: 成功 n 筆、失敗 m 筆`，或中止、錯誤提示。

### 結果清單

三欄表格：`清單列號`（對應 Excel 的列號）、`結果`（成功／失敗／中止／略過）、`訊息`（失敗原因原文）。成功列為綠色、失敗列為紅色、其他為灰色，並自動捲到最新一列。

## 清單欄位格式

工作表「EXCEL貼值清單」的結構（第 1 列標題、第 2 列起資料）：

| 欄 | 標題 | 內容 | 範例 |
|---|---|---|---|
| A | 來源EXCEL檔案路徑 | 來源活頁簿完整路徑 | `D:\報表\來源.xlsx` |
| B | 來源工作頁名稱 | 工作表名稱，或工作表序號 | `Sheet1` 或 `1` |
| C | 來源儲存格位置 | 來源範圍；`D` 欄為 `Y` 時此欄可留空 | `A1:B10` |
| D | 來源範圍是否為UsedRange(Y) | 填 `Y` 表示改用整張工作表的 UsedRange | `Y` |
| E | 目的EXCEL檔案路徑 | 目的活頁簿完整路徑 | `D:\報表\目的.xlsx` |
| F | 目的工作頁名稱 | 工作表名稱，或工作表序號 | `報表` 或 `2` |
| G | 目的儲存格位置 | 貼上的起始範圍 | `C5` |
| H | 目的儲存格為合併儲存格(Y) | 填 `Y` 表示以指定值方式寫入（適用合併儲存格） | `Y` |
| I | 錯誤訊息 | **由程式寫入**，執行前會被清空 | `成功` |

補充說明：

- 讀取時 A～H 欄一律當文字處理，數字 `1.0` 會轉成 `1`，前後空白會去除。
- 工作表名稱比對**不分大小寫**；若找不到同名工作表，且欄位內容是數字 `N`，就改用第 `N` 張工作表（從 1 起算）。序號超出範圍會視為「工作表不存在」。
- A 欄與 E 欄**同時空白**的列會直接跳過，不會出現在結果清單，`I` 欄也保持空白。
- 資料只讀到 A 欄最後一筆有值的列為止，下方空白列不處理。

## 貼值規則

程式行為與原本的 VBA 版一致，重點如下：

1. **同一個檔案只開啟一次**，處理完所有列才統一儲存、關閉，避免反覆開關檔案。
2. 來源檔如果同時也是目的檔，會改以**可寫入**方式開啟；純來源檔則以唯讀開啟。
3. 貼值成功才把目的檔標記為「需要儲存」；某列失敗不會觸發儲存，但其他成功列照樣會存。
4. `I` 欄舊內容會在開始時整批清空後重寫，`D1`、`I1` 兩個標題也會被程式覆寫。
5. 清單檔本身最後才儲存，確保結果有寫進檔案。

單列的貼值判斷：

```mermaid
flowchart TD
    S["讀取一列的 A~H 欄"] --> T1{"D 欄 = Y ?"}
    T1 -->|是| U["來源範圍 = 整張工作表的 UsedRange<br/>C 欄位址忽略"]
    T1 -->|否| V["來源範圍 = C 欄位址"]
    U --> W{"H 欄 = Y ?"}
    V --> W
    W -->|是| X["以 Value 直接指定貼值"]
    W -->|否| Y["複製來源後<br/>PasteSpecial 貼上值"]
    X --> Z["目的檔標記為需儲存"]
    Y --> Z
```

- `H` 填 `Y` 時走「直接指定值」，適合目的端是合併儲存格的情況；此時來源與目的的範圍大小建議一致。
- `H` 留空時走「複製 → 選擇性貼上（值）」，只貼值、不帶格式。

## 輸出結果

程式**不會產生新檔案**，結果直接寫回你指定的檔案：

| 寫入位置 | 內容 | 時機 |
|---|---|---|
| 清單檔 `I` 欄 | `成功` 或錯誤訊息原文 | 全部列處理完，儲存清單檔時 |
| 清單檔 `D1`、`I1` | 固定標題 `來源範圍是否為UsedRange(Y)`、`錯誤訊息` | 開始處理時 |
| 目的檔 | 貼上的值 | 該列成功後，於統一儲存階段寫入 |

`I` 欄可能出現的訊息：

| 訊息 | 意義 |
|---|---|
| `成功` | 該列貼值完成，目的檔已（或將）儲存 |
| `使用者已中止，後續列未處理` | 你按了「中止」，此列（含）之後沒有處理 |
| `無法開啟來源檔案: …` | 來源檔路徑空白、不存在，或無法開啟 |
| `無法開啟目的檔案: …` | 目的檔路徑空白、不存在，或無法開啟 |
| `來源工作表不存在: <名稱>` | B 欄名稱或序號找不到對應工作表 |
| `目的工作表不存在: <名稱>` | F 欄名稱或序號找不到對應工作表 |
| `來源範圍無效: <位址>` | C 欄位址格式錯誤（例如打成 `A1B10`） |
| `目的範圍無效: <位址>` | G 欄位址格式錯誤 |
| `複製資料時發生錯誤: …` | 貼值時 Excel 回報錯誤，例如工作表被保護 |
| `處理時發生錯誤: …` | 該列發生未預期錯誤 |
| `儲存目的檔案時發生錯誤: …` | 貼值成功但存檔失敗（檔案唯讀或被鎖定） |

若整份清單沒有任何資料，`I` 欄不會有訊息，結果清單會出現一列 `略過 / 清單無資料`。

## 資料安全與備份

- 程式**不會連網**，所有處理都在本機，並透過你電腦上的 Excel 完成。
- 程式**只會讀寫你在清單中指定的檔案**，以及清單檔本身（`D1`、`I1`、`I` 欄）。
- 目的檔會被**直接覆寫儲存**，沒有復原／Undo 功能。建議第一次使用先在測試副本上跑，或先備份目的檔。
- 執行期間會開啟一個隱藏的 Excel 實例，結束時自動關閉。若程式被強制結束，可能在工作管理員留下 `EXCEL.EXE` 行程。

## 常見問題與排錯

### 按「開始執行」出現「請先安裝 pywin32」

你正在用原始碼（`paste_excel_tool.py`）執行，且環境缺少 `pywin32`。

改用免安裝執行檔 `dist\PasteExcelTool.exe`，或在命令列執行 `pip install -r requirements.txt` 後再啟動。

### 彈出「程式發生未預期錯誤：清單檔中找不到工作頁」

「清單工作頁」欄位的名稱和檔案裡實際的工作表名稱不一致。

確認 Excel 下方的工作表標籤名稱，並注意名稱不含前後空白。若你的清單放在其他工作表，請直接修改「清單工作頁」欄位。

### 出現「無法開啟來源檔案」或「無法開啟目的檔案」

常見原因是路徑空白、檔案不存在，或檔案正被 Excel 開著而處於鎖定狀態。

1. 確認路徑是完整絕對路徑，且檔名與副檔名正確。
2. 關閉 Excel 中所有相關活頁簿（包含背景殘留的 `EXCEL.EXE`）再重試。
3. 確認檔案不是唯讀、不在被同步工具鎖定的網路磁碟上。

### 出現「來源工作表不存在」或「目的工作表不存在」

B 欄／F 欄的名稱打錯，或填了數字但超出來源檔的工作表張數。

改成實際的工作表名稱（不分大小寫），或改成 1～工作表張數之間的數字。

### 出現「來源範圍無效」或「目的範圍無效」

位址格式不正確。位址要像 `A1`、`A1:B10`，不能寫成 `A1B10`、`Sheet1!A1`。

### 出現「複製資料時發生錯誤」

通常是目的工作表被保護、儲存格被鎖定，或合併儲存格大小與來源範圍不相符。

先取消工作表保護，或在 `H` 欄填入 `Y` 改用直接指定值的方式，並確認來源與目的範圍大小一致。

### 出現「儲存目的檔案時發生錯誤」

貼值成功但存檔失敗，多半是檔案唯讀或被其他程式鎖定。

關閉佔用該檔案的程式、取消唯讀屬性後重新執行。注意該列在 `I` 欄會顯示這則訊息，代表資料可能只存在記憶體、未寫入檔案。

### 按「中止」後程式沒有馬上停

這是設計行為：中止只在「每列開始前」檢查，目前這一列會先做完。

想立即停止請關閉程式視窗，但可能留下未儲存的結果與殘留的 `EXCEL.EXE` 行程。

### 狀態一直停在「處理中」沒有進度

通常是檔案很大、檔案在慢速網路磁碟，或 Excel 正在等待你處理某個對話框。

先確認沒有 Excel 對話框被隱藏，必要時關閉程式、清理 `EXCEL.EXE` 行程後分批處理（把清單拆成多份）。

### 雙擊 exe 出現「Windows 已保護您的電腦」

執行檔沒有數位簽章，SmartScreen 因此示警。

點「更多資訊」→「仍要執行」即可；若公司政策封鎖，請改用原始碼執行。

## 從原始碼建置

一般使用者不需要本節，直接用 `dist\PasteExcelTool.exe` 即可。

專案檔案：

```text
paste_excel_tool.py      主程式（tkinter 介面 + Excel COM 處理）
requirements.txt         執行期相依（pywin32）
build.bat                一鍵重新打包
PasteExcelTool.spec      PyInstaller 打包設定
dist\PasteExcelTool.exe  打包產出（免安裝執行檔）
```

建置步驟：

```bat
build.bat
```

等同手動執行：

```bat
python -m pip install -r requirements.txt
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name PasteExcelTool paste_excel_tool.py
```

驗證方式：產出 `dist\PasteExcelTool.exe` 後雙擊，確認視窗正常顯示、可選檔並執行一次小規模清單。若需要自訂圖示，在 PyInstaller 指令加上 `--icon=app.ico` 後重新打包。
